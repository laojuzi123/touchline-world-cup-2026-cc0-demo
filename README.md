# Touchline | World Cup 2026 Results Companion

A self-contained interactive portfolio companion for exploring all 104 matches of the 2026 FIFA World Cup. It includes match scores, goal timelines, team totals, and filters.

**Data:** [OpenFootball World Cup 2026](https://github.com/openfootball/worldcup.json/blob/516d3825c3bd23fdc298c4014e84bde78f2d4965/2026/worldcup.json), published under CC0-1.0. The dataset is pinned to commit `516d3825c3bd23fdc298c4014e84bde78f2d4965`. The interface is an independent portfolio prototype.

This public demo contains only CC0 match results and goal summaries. The separate xG case study describes a locally evaluated model but its event source has no confirmed reuse licence, so no event rows, shot locations, xG estimates or event-derived charts are published here.

Open `index.html` directly or visit the GitHub Pages site.
