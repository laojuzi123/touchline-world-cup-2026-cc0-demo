HOW TO READ THIS

Evaluation after the group stage

The holdout contains 773 non-penalty shots from 32 knockout matches. Lower Brier score and log loss indicate better probability estimates than the constant-rate baseline in this sample.

  • Each plotted point pools 128–129 shots.
  • The dashed line represents perfect calibration.
  • One competition cannot establish performance in other seasons, leagues or providers.

03 / METHODOLOGY

Built to be inspected.

The public preview shows a model calculation and summary evaluation while keeping the source event feed out of the deployed files.

01 / QUESTION

What makes a shot more likely to score?

Distance, opening angle, body part, set pieces, direct free kicks, fast breaks and assisted status enter the model before the shot outcome is known.

02 / VALIDATION

Train on one stage. Test on the next.

1738 group-stage shots train the model. 773 knockout shots remain unseen until evaluation. A constant-rate prediction provides a benchmark.

03 / LIMITS

Important context is missing.

There are no defender, goalkeeper or player-ability features. The trained coefficients and aggregate metrics are shared; event rows and real shot charts are not.
